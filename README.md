<h4> Belajar ADT untuk Struktur Data </h4>
<p> Berdasarkan Diktat Struktur Data oleh Anggraeni Liem, ADT adalah definisi type dan operasi dasar (disebut primitif) terhadap type tersebut. 
  Dalam ADT terdapat persyaratan tertentu yang selalu berlaku. Definisi type suatu ADT dapat mengandung definisi ADT lain. 
Type diterjemahkan menjadi type terdefinisi dalam bahasa bersangkutan, seperti struct dalam bahasa C. Sementara itu, primitif 
diterjemahkan menjadi fungsi atau prosedur. Primitif umumnya dikelompokkan menjadi konstruktor, selektor, mutator, predikat,
baca/tulis, aritmatika, dan konversi.</p> 
<p> ADT biasa direalisasikan dalam 2 (dua) modul, yaitu definisi dan spesifikasi type yang bersangkutan dan body atau realisasi dari
primitif berupa koda program bahasa tertentu.</p>
